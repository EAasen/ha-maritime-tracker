# Quick Fix: v1.2.5 Location Validation Error

## Problem
You're getting this error when setting up the integration:
```
Unknown error occurred
not a valid option at 'location'
```

## Solution

This has been **fixed in the latest commit**. Here's what to do:

### For Home Assistant Users (HACS Installation)

1. **Update the integration:**
   - Go to Home Assistant Settings → Devices & Services → Integrations
   - Find "Norwegian Maritime Tracker"
   - Click the menu (three dots) → Uninstall
   - Go back to integrations and search for "Norwegian Maritime Tracker"
   - Click it and select "Create Integration"
   - Now proceed through the setup flow normally

2. **Or, if HACS doesn't show an update:**
   - Go to Settings → Devices & Services → Integrations
   - Click on "Norwegian Maritime Tracker"
   - Click "Reload"
   - Create a new integration entry

### For Developers (Direct Installation)

If you installed this locally:

```bash
cd ha-maritime-tracker
git pull origin main
```

Then restart Home Assistant.

## What Was Fixed

The issue was a **schema validation error** in the location form step. The form was trying to validate the location data before it was properly formatted, causing voluptuous to throw a generic error.

### Changes Made:
- ✅ Added a proper validator for the location field
- ✅ Removed problematic default values that caused validation to fail
- ✅ The validator now runs correctly when you submit the map location
- ✅ Better error messages if something goes wrong

## How It Works Now

1. You see the map with Norwegian coordinates pre-centered
2. You click to select a location on the map
3. You adjust the radius if needed
4. You click "Submit"
5. The form validates your location and accepts it
6. No more "not a valid option" error!

## If You Still See the Error

1. **Clear browser cache:**
   - Ctrl+Shift+Delete (or Cmd+Shift+Delete on Mac)
   - Clear cache

2. **Reload Home Assistant:**
   - Settings → System → Server Controls → "Restart Home Assistant"

3. **Check HA version:**
   - This fix requires Home Assistant 2026.10.4 or later
   - Settings → About to check your version

## Troubleshooting

| Issue | Solution |
|-------|----------|
| Still see error after update | Restart Home Assistant completely |
| Location outside Norway | Try clicking on a location within Norwegian waters (between 57°N-71.5°N, 4°E-32°E) |
| No map appears | Ensure your Home Assistant has internet access; the map requires loading map tiles |
| Can't select location | Try a different browser or clear browser cache |
