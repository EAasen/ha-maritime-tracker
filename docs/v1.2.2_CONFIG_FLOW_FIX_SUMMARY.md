## What Was Fixed in Config Flow

### The Problem
When users tried to confirm their location selection in the config flow's "Tracking Area" step, they were getting a generic error: "not a valid option at 'location'". This provided no actionable guidance on what went wrong.

### The Root Cause
The `LocationSelector` in Home Assistant wasn't properly validating the submitted location dictionary. The code tried to access fields without checking if they existed first, causing voluptuous schema validation to fail with a generic, unhelpful error message.

### The Solution
Enhanced the `async_step_radius()` method to:

1. **Check if location exists** - Ensure the location field was provided
2. **Validate format** - Check that location is a dictionary
3. **Validate coordinates** - Ensure latitude and longitude are present
4. **Validate bounds** - Check that location is within Norwegian waters
5. **Handle radius** - Use default radius if not provided
6. **Provide clear errors** - Return specific error messages for each issue

### Code Changes

**File:** `custom_components/marinetraffic_tracker/config_flow.py`

**Added:**
- Type validation for location data
- Bounds checking using existing `_is_within_norway()` function
- Fallback to default radius when not provided
- Specific error messages for each validation failure
- Debug logging for troubleshooting

**File:** `custom_components/marinetraffic_tracker/strings.json`

**Added 5 New Error Messages:**
```json
"location_required": "You must select a location on the map.",
"invalid_location_format": "The location data format is invalid. Please try selecting the location again.",
"location_missing_coordinates": "The location is missing latitude and/or longitude. Please try selecting the location again.",
"location_outside_norway": "The selected location is outside Norwegian waters. Please select a location within Norway.",
"invalid_location_data": "There was an error processing the location. Please try selecting the location again."
```

## How to Test

### Manual Testing

1. **Go through config flow:**
   - Settings → Devices & Services → Create Automation
   - Search for "Norwegian Maritime Tracker"
   - Follow setup through credentials and mode selection

2. **Test valid location:**
   - When you reach "Tracking Area" step
   - Click on the map in Norwegian waters (e.g., near Bergen or Oslo)
   - Adjust the radius as needed
   - Submit - should move to options step ✅

3. **Test error scenarios:**

   **Missing location:**
   - Try submitting without clicking on map
   - Expected: "You must select a location on the map." ✅

   **Outside Norway:**
   - Click on Sweden, Germany, or other non-Norwegian country
   - Submit
   - Expected: "The selected location is outside Norwegian waters." ✅

   **No radius selected:**
   - Select location but don't adjust radius
   - Submit
   - Expected: Should still work with default radius ✅
