## Summary

## What's New

### 🔧 Home Assistant 2026.10.4+ Compatibility Fix

**Issue:** Home Assistant 2026.10.4 removed the `allow_user_context` parameter from WebSocket API registration.

**Status:** ✅ Fixed in v1.2.2

**Changes Made:**
- Updated WebSocket API registration to use modern import-based approach
- Removed deprecated `allow_user_context` parameter
- Ensured `hass` is passed as first parameter to `async_register_command()`

**Files Modified:**
- `custom_components/marinetraffic_tracker/websocket_api.py` (Lines 20, 96-121)

**Impact:**
- ✅ Zero user-facing changes
- ✅ All existing configurations remain valid
- ✅ No entity changes
- ✅ No data migration required

See [CODE_CHANGES_v1.2.2.md](CODE_CHANGES_v1.2.2.md) for detailed code diff.

## Known Issues

### Activation Error After Upgrade

**Issue:** Getting `TypeError: async_register_command() got an unexpected keyword argument 'allow_user_context'`

**Cause:** Stale Python bytecode cache in Home Assistant

**Solution:** 
1. Remove integration from Home Assistant
2. Delete `/config/custom_components/marinetraffic_tracker/`
3. Clear Python cache: `find /config -type d -name __pycache__ -exec rm -rf {} + 2>/dev/null`
4. Reinstall through HACS
5. Restart Home Assistant

See [README_v1.2.2_FIX.md](README_v1.2.2_FIX.md) for complete step-by-step instructions.

## Technical Details

### WebSocket API Changes

| Aspect | v1.2.1 | v1.2.2 |
|--------|--------|--------|
| **Import Pattern** | `hass.components.websocket_api` | `from homeassistant.components import websocket_api` |
| **API Call** | `hass.components.websocket_api.async_register_command(cmd, handler, allow_user_context=False)` | `websocket_api.async_register_command(hass, cmd, handler)` |
| **HA Versions** | 2026.10.3 and earlier | 2026.10.4+ |
| **Status** | ❌ Deprecated | ✅ Current |

### Verification

You can verify the fix is installed correctly:

```bash
# Check no deprecated usage remains
grep -n "hass\.components\.websocket_api" /config/custom_components/marinetraffic_tracker/websocket_api.py
# Expected output: (nothing)

# Check allow_user_context is removed
grep -n "allow_user_context" /config/custom_components/marinetraffic_tracker/websocket_api.py
# Expected output: (nothing)

# Verify version
cat /config/custom_components/marinetraffic_tracker/manifest.json | grep version
# Expected output: "version": "1.2.2"
```

## Installation & Upgrade

### For HACS Users
1. Open HACS → Integrations
2. Find "Norwegian Maritime Tracker"
3. Click on it and select "Update" (if available)
4. Restart Home Assistant when prompted

### For Manual Installation
1. Download the latest release: https://github.com/EAasen/ha-maritime-tracker/releases/tag/v1.2.2
2. Extract and copy `custom_components/marinetraffic_tracker/` to your `config/custom_components/`
3. **Important:** Clear Python cache (see "Known Issues" section)
4. Restart Home Assistant

### Troubleshooting Installation

If you see the `allow_user_context` error after upgrade:
1. Follow the 5-step fix in [README_v1.2.2_FIX.md](README_v1.2.2_FIX.md)
2. Or run the aggressive cache clearing in [TROUBLESHOOTING_v1.2.2.md](TROUBLESHOOTING_v1.2.2.md)
