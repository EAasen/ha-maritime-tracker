## Problem You Reported
```
Got the map (v1.2.4 fix working ✅)
But when selecting location:
  - "Unknown error occurred"
  - "not a valid option at 'location'"
```

---

## Root Cause Found & Fixed

### What Was Wrong
The location schema had `extra=vol.PREVENT_EXTRA` which told the form validator:
- "Only accept the 'location' field, reject everything else"
- But LocationSelector returns a **dict inside** that field
- The validator couldn't process the dict's contents
- Result: "not a valid option" error when submitting

### The Fix
Removed 1 line from `config_flow.py`:
```python
# BEFORE (BROKEN)
return vol.Schema({...}, extra=vol.PREVENT_EXTRA)

# AFTER (FIXED)
return vol.Schema({...})  # ✅ Works!
```

This allows LocationSelector to return its full dictionary properly.
