## 🔧 Home Assistant 2026.11.0+ Compatibility Fix

### 🐛 Bug Fix

Fixed critical issue where users on Home Assistant 2026.11.0+ were getting:
```
not a valid option at 'location'
```

When selecting a location on the map during config flow setup.

**Root Cause:** Home Assistant 2026.11.0 introduced stricter validation for LocationSelector that conflicts with the previous schema validation approach.

**Solution:** Implemented a permissive validator that:
- Bypasses strict LocationSelector validation
- Keeps the map UI widget working properly
- Moves all validation to the handler with clear error messages
- Compatible with all HA versions (2026.10.4+)

### 📋 What's New

#### New Permissive Validator
- Added `_accept_location_dict()` function
- Accepts any dictionary format from LocationSelector
- Prevents voluptuous validation conflicts

#### Improved Handler Validation
- Comprehensive validation in `async_step_radius()`
- Better logging for debugging
- Specific error messages for each failure case

#### Better Error Messages
- "You must select a location on the map"
- "The location is missing latitude/longitude"
- "The selected location is outside Norwegian waters"
- "There was an error processing the location"

### 🚀 How to Update

**HACS Users:**
1. Settings → Devices & Services → Integrations
2. Find "Norwegian Maritime Tracker"
3. Click Update
4. Restart Home Assistant

**Manual Installation:**
```bash
cd ha-maritime-tracker
git pull origin main
# Restart Home Assistant
```

### 📝 Testing

After updating:
1. Create a new integration entry
2. Select "Radius (map selector)"
3. Click on the map to select a location
4. Adjust radius if needed
5. Click Submit → Should work now! ✅
